# 消防小本本壓力測試紀錄

測試日期：2026-10-21（Asia/Taipei）。檢查對象為本機交付版 `Code.gs`、`Index.html`、`UI-Preview.html` 與 `部署指南.md`；執行方式為 Node.js 語法檢查、DOM/API 靜態審計及 GAS／Drive／Tasks 模擬測試。

## 執行結果

| 項目 | 結果 | 檢查內容 |
|---|---|---|
| 響應式 UI 與預覽同步 | 通過（程式碼審計） | 檢查 viewport、iOS 安全區、390px／760px 斷點及動態視窗高度。預覽版 CSS（排除提示條）與正式版相同，正式互動腳本逐字一致。未連接實機瀏覽器。 |
| 圖片壓縮與附件限制 | 通過（模擬） | 檢查 Canvas JPEG 品質 0.75；橫式 4000×2000 縮為 1600×800，直式 3024×4032 縮為 1200×1600；HEIC 無法轉 JPEG 時會阻止送出。前端依完整 JSON 限制 6 MiB，後端限制原始附件 5 MiB 並另驗 JSON。未測真實 iPhone 相機、弱網速度或 Drive 實際上傳。 |

| 進度附件預覽與 DOM 重繪 | 通過（靜態檢查） | `progressFiles` 選檔會更新檔名清單，開關視窗時清除；新建成功流程只執行一次篩選與卡片重繪。 |
| Active 集合與台北跨日 | 通過（模擬） | 台北時間 23:59／00:01 的日期切換與後端時區一致；逾 90 天已結案案件移出 `activeIds`，舊未結案及近 90 天案件仍在集合。 |

| 垃圾桶資料夾與孤兒索引 | 通過（模擬／程式碼審計） | 案件資料夾位於 Drive 垃圾桶時，更新與重新命名都會給明確錯誤；每日清理會移除主表中已不存在的索引 ID，連續列以批次刪除。 |

## 本機測試的範圍

測試是對本機原始碼執行的自動化模擬及靜態審計，不會呼叫 Apps Script、Google Drive 或 Google Tasks 真實服務。沒有連接真實 iPhone、Android、桌面瀏覽器，也沒有在正式 Google 試算表載入數千筆資料。因此不代表手機瀏覽器相容性、Google API 配額、授權流程或實際弱網上傳已實機驗證；部署後仍應依部署指南用自己的 Gmail 做一輪小量驗收。

## 本輪加固內容

- 以 request marker 對照一次掃描結果，讓附件重送時時間軸名稱與 Drive 實際檔名一致，並減少 Drive I/O。
- 進度彈窗顯示所選附件檔名；前端 Active 集合依台北日期、狀態重新計算。
- metadata 回傳列號 Map，避免 hydrate 再讀一次 A 欄；阻止把附件寫入垃圾桶資料夾。
- 每日清理孤兒索引；月備份最多保留 24 份。
- Tasks 清單改名時嘗試原位復原，整份刪除時重新定位或建立。
- UI Preview 由正式 `Index.html` 產生，除示範橫幅與模擬 API 外，CSS 和互動程式碼保持同步。
